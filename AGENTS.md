# Working on Veritas Agent

Start with the [two-turn example](README.md#try-a-follow-up). Keep Ask Veritas on one page and reuse the Home Veritas artwork and arrow. Use Conventional Commits. Work locally until Rafael approves a push or deployment.

The README maps the code and Cloudflare bindings. Preserve the original publisher, URL, wording and check date when changing a quotation. Preserve the wording and agreed scope of the [project prompts](PROMPTS.md).

Keep buyer conversations in browser storage. The shared store accepts public topic IDs, receipt votes, counters and public guide replays. Send only public guide replays to Jev. Keep microphone recordings out of server and browser storage. Keep credentials, model settings, expanded source snapshots, prepared speech weights, local databases and eval reports outside Git.

Run the [verification skill](.agents/skills/verify-veritas/SKILL.md) for changes to chat, feedback, retrieval or the daily review. Use fictional buyer questions in tests and screenshots.

Audit the app and the separate `evals/` lockfile after dependency changes. The eval toolchain pins patched versions of the CLI's HTTP server and file matching dependencies.
